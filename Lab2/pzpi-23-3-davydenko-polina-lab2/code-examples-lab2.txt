1. Запит для створення базового застосунку
Запит до ШІ: я ніколи не працювала з android. поясни як створити простий застосунок на kotlin з jetpack compose. мені потрібно просто відобразити список елементів на екрані, покажи приклад коду і поясни де що вставляти
Результат: ШІ показав, як виглядає базовий Android проєкт і де знаходиться MainActivity. Також дав приклад Compose-функції та пояснив, як працює setContent. Було показано використання LazyColumn для відображення списку. Я використала цей приклад як основу і потім замінила тестові дані на дані з сервера.
Фрагмент коду, отриманий від ШІ:
@Composable
fun SimpleList() {
    val items = listOf("Item 1", "Item 2", "Item 3")

    LazyColumn {
        items(items) { item ->
            Text(text = item)
        }
    }
}

Запит до ШІ: поясни дуже просто як підключити retrofit в android studio та як працюють api. покажи залежності і приклад клієнта
Додатковий запит: що таке gson і навіщо він потрібен? чи потрібно його підключати окремо?
Результат: ШІ дав список залежностей, які потрібно додати в Gradle. Також пояснив, що Retrofit використовується для запитів до сервера, а Gson щоб автоматично перетворювати JSON у Kotlin-об’єкти. Було показано приклад RetrofitClient. Я вставила цей код у свій проєкт і змінила адресу сервера на свою.
Фрагмент коду, отриманий від ШІ:
object RetrofitClient {
    private const val BASE_URL = "http://localhost:5000/"

    val api: ApiService by lazy {
        Retrofit.Builder()
            .baseUrl(BASE_URL)
            .addConverterFactory(GsonConverterFactory.create())
            .build()
            .create(ApiService::class.java)
    }
}

Додатковий запит: як передати параметри в post запиті у вигляді json?
Результат: ШІ пояснив, як створюється інтерфейс з анотаціями @GET, @POST. Також показав, як передавати дані через @Body у вигляді Map. Я використала цей підхід і підставила свої URL та параметри, які відповідають моєму серверу
Фрагмент коду, отриманий від ШІ:

    fun getMenu(): Call<List<Dish>>

}

5. Запит для отримання даних
Запит до ШІ: як у jetpack compose отримати дані з api і показати їх у списку? як працює асинхронність
Додатковий запит: що таке enqueue і callback? поясни дуже просто
Результат: ШІ пояснив, що запит виконується не одразу, а у фоні, і коли приходить відповідь - викликається callback. Було показано приклад enqueue. Я використала цей код і підключила свій API, після чого дані почали відображатись у списку.
Фрагмент коду, отриманий від ШІ:
api.getMenu().enqueue(object : Callback<List<Dish>> {
    override fun onResponse(call: Call<List<Dish>>, response: Response<List<Dish>>) {
        if (response.isSuccessful) {
            dishes = response.body() ?: emptyList()
        }
    }

    override fun onFailure(call: Call<List<Dish>>, t: Throwable) {
        println("Error")
    }
})

10. Запит для оновлення списку
Запит до ШІ: як зробити так, щоб після видалення елемента список оновлювався?
Результат: ШІ порадив після видалення ще раз викликати функцію завантаження даних. Я зробила окрему функцію loadData і викликала її після кожної зміни. Завдяки цьому список завжди показує актуальні дані.
Фрагмент коду, отриманий від ШІ:
fun loadData() {
    api.getItems(orderId).enqueue(object : Callback<List<Map<String, Any>>> {
        override fun onResponse(
            call: Call<List<Map<String, Any>>>,
            response: Response<List<Map<String, Any>>>
        ) {
            items = response.body() ?: emptyList()
        }

        override fun onFailure(call: Call<List<Map<String, Any>>>, t: Throwable) {}
    })
}
