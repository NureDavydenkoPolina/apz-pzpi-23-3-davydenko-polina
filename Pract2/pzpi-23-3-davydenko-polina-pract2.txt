2 ЗАВДАННЯ
	Метою роботи є дослідити архітектуру складної програмної системи Reddit, проаналізувати її структурну організацію, взаємодію компонентів, принципи масштабування та використані технології. 

3 ОПИС ВИКОНАНОЇ РОБОТИ
	У процесі виконання практичного заняття було обрано вебплатформу Reddit для аналізу архітектури програмної системи. Було досліджено основні компоненти системи, архітектурний стиль, принципи взаємодії сервісів та використання баз даних і кешування.
	Під час роботи було розглянуто мікросервісну архітектуру Reddit;  основні backend-сервіси; використання PostgreSQL та Redis; принципи масштабування системи.

ВИКОРИСТАННЯ ШІ ПІД ЧАС РОЗРОБКИ
Назва інструменту та версія: модель GPT-5.5, план Go
Мета використання: Штучний інтелект використовувався для пошуку та структурування інформації про архітектуру програмної системи Reddit, формування плану доповіді, створення UML-діаграм та підготовки матеріалів для презентації.
Внесок автора: Самостійно було обрано тему роботи, виконано аналіз отриманої інформації, оформлено презентацію, створено слайди та відредаговано матеріали відповідно до вимог практичного заняття.
Використані запити
1. Запит для вибору програмної системи
Запит до ШІ: мені потрібно зробити доповідь про архітектуру складної програмної системи. наведи якнайбільше сучасних вебсервісів або платформ, у яких є хоча б частково відкритий код або технічна документація. бажано щось типу spotify, figma, але не такі популярні системи
Додатковий запит: які з цих систем найкраще підійдуть саме для теми архітектури програмних систем та uml-діаграм?
Результат: Було отримано список сучасних платформ та сервісів із коротким описом їх архітектури. На основі цього було обрано Reddit як тему для аналізу.

2. Запит для створення структури доповіді
Запит до ШІ: допоможи скласти план презентації для доповіді про архітектуру reddit. потрібно коротко, без зайвого тексту, але щоб були основні компоненти системи, бази даних, масштабування та uml-діаграми.
Результат: Було сформовано структуру презентації зі слайдами про архітектуру Reddit, компоненти системи, бази даних, масштабування та висновки.

3. Запит для UML-діаграми компонентів
Запит до ШІ: створи uml component diagram для reddit у форматі plantuml. на діаграмі мають бути web client, mobile app, api gateway, auth service, post service, comment service, postgresql та redis.
Додатковий запит: зроби діаграму саме як uml component diagram, а не просто блок-схему.
Результат: Було отримано повну структуру для UML-діаграми компонентів.

4. Запит для UML Activity Diagram
Запит до ШІ: створи uml activity diagram у для процесу створення поста в reddit: авторизація користувача, створення поста, перевірка даних, збереження в базу даних та відображення поста.
Результат: Було створено UML Activity Diagram процесу створення поста користувачем у Reddit.



4 ВИСНОВКИ
	У результаті виконання роботи було досліджено архітектуру програмної системи Reddit та її основні компоненти. Було визначено, що Reddit використовує сучасний мікросервісний підхід, який забезпечує масштабованість, продуктивність та стабільну роботу системи.
