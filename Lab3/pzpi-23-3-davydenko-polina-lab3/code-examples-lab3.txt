ВИКОРИСТАННЯ ШІ ПІД ЧАС РОЗРОБКИ
Назва інструменту та версія: модель GPT-5.3, план Go
Мета використання: ШІ використовувався як допоміжний інструмент під час розробки front-end частини застосунку SmartFood. Зокрема для вирішення питань по JavaScript, роботі з API, організації коду, мультимовності та створення UML-діаграм.
Внесок автора: Я самостійно написала HTML, CSS і основну логіку на JavaScript (меню, кошик, замовлення, адмінка). Також сама підключала бекенд, тестувала API і робила діаграми. ШІ використовувався для підказок, пояснень і перевірки.
Використані запити
1. Запит для структури фронтенду
Запит до ШІ: я роблю веб-застосунок без React, просто HTML, CSS і JS. як краще розділити код по файлах? у мене буде меню, адмінка і робота з API.
Результат: Було запропоновано розділити код на окремі файли: main.js для користувацького інтерфейсу, admin.js для адмінки, api.js для запитів і окремий файл для перекладів. 
2. Запит для роботи з fetch
Запит до ШІ: коротко різниця між async/await і обробка помилок.
Додатковий запит: як передавати JSON у POST запиті?
Результат: Я отримала приклади використання async/await, а також пояснення як працює fetch. 
3. Запит для авторизації
Запит до ШІ: як зберігати токен після логіну? і як його потім використовувати?
Додатковий запит: чи нормально використовувати localStorage?
Додатковий запит: як додавати токен в headers?
Додатковий запит: що робити якщо токен неправильний?
Результат: Було пояснено, що токен можна зберігати в localStorage і додавати в Authorization header. Також я додала обробку помилок і автоматичний logout.
4. Запит для кошика
Запит до ШІ: як краще зробити кошик у JS?
Додатковий запит: як варто змінювати кількість товару?
Результат: Було запропоновано використовувати масив об’єктів і зберігати його в localStorage. Я реалізувала логіку додавання і зміни кількості.
5. Запит для рендеру меню
Запит до ШІ: як відобразити список страв з бекенду на сторінці?
Додатковий запит: чи можна використовувати innerHTML?
Додатковий запит: як краще зробити кнопки для кожної страви?
Результат: Було пояснено як працює map() і як генерувати HTML. Я зробила відображення карток страв.
6. Запит для мультимовності
Запит до ШІ: як зробити щоб можна було перемикати сайт з української на англійську і навпаки?
Результат: Було запропоновано зробити словник перекладів і оновлювати текст через JS. Я зробила i18n.js.
9. Запит для адмінки
Запит до ШІ: як розділити ролі користувачів? у мене є admin, cook і waiter.
Додатковий запит: де зберігати роль?
Результат: Було запропоновано зберігати роль в localStorage і перевіряти її в коді. Я зробила різний функціонал для ролей.
10. Запит для UML діаграм
Запит до ШІ: я не розумію різницю між component diagram і package diagram. можеш пояснити просто?
Результат: Було пояснено, що component diagram - це про архітектуру, а package - про структуру коду.
