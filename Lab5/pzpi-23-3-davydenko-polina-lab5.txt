2 ЗАВДАННЯ
	Метою роботи є підготовка презентації програмного проєкту SmartFood, розробленого протягом двох семестрів. Необхідно продемонструвати основні можливості системи, показати реалізований функціонал веб та Android-застосунків, адміністративної панелі, а також описати використані технології, архітектуру системи та можливості подальшого розвитку проєкту.


3 ОПИС ВИКОНАНОЇ РОБОТИ
	Під час виконання лабораторної роботи було створено презентацію програмної системи SmartFood для автоматизації ресторанного обслуговування.
	У презентації було представлено архітектуру системи, основні компоненти та використані технології. Серверна частина системи реалізована на Python із використанням Flask та SQLAlchemy, база даних працює на Microsoft SQL Server. Також було реалізовано веб-застосунок та Android-застосунок на Kotlin.
	У межах демонстрації було показано роботу клієнтських застосунків, створення та обробку замовлень, адміністративну панель із підтримкою ролей адміністратора, кухаря та офіціанта, а також систему локалізації українською та англійською мовами.
	Додатково було продемонстровано підтримку резервного копіювання бази даних, Docker-контейнеризацію, використання Nginx для масштабування та базову IoT-інтеграцію для відображення замовлень у системі ресторану.

Назва інструменту та версія: модель GPT-5.3, план Go
Мета використання: Використання ШІ для допомоги у структуризації презентації проєкту SmartFood та підготовці тексту для виступу та уточненні структури слайдів.
Внесок автора: Я самостійно розробила серверну частину системи, Android-застосунок, веб-застосунок, адміністративну панель, систему ролей, REST API, локалізацію, Docker-конфігурацію та IoT-інтеграцію. Додатковий запит до ШІ: запропонуй порядок слайдів так, щоб презентація виглядала як завершений програмний продукт
